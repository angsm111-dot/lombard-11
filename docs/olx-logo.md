# Logo OLX

Plik: `dist/assets/olx-logo.svg`.
Źródło: https://commons.wikimedia.org/wiki/File:OLX_green_logo.svg
Plik źródłowy: https://upload.wikimedia.org/wikipedia/commons/9/9e/OLX_green_logo.svg

Używany do oznaczenia odnośnika do ogłoszeń Lombardu Sezam na OLX. Nie oznacza partnerstwa ani rekomendacji przez OLX. Obrys logo nie został zmieniony. Turkusowy kolor otaczającego kafla jest elementem strony Sezam. Zachowano wcześniejsze przekrzywienie kafla.
